- [ ] 搬走源码及 `package-lock.json`，而非只有exe或空 `.git`。交接时没有commit/remote。
- [ ] 单独搬走被忽略的 `artifacts/handoff-fixtures/`，11个PNG与manifest；不要把整个诊断目录公开。
- [ ] Windows、Node>=22.12、npm、中文SAPI语音可用。`npm ci`恢复依赖，`npm run build`准备离线OCR。
- [ ] `WATCHMATE_FIXTURES`指向新绝对路径，校验hash成功。
- [ ] 按需运行check/tests/build/recognition并核对报告；桌面与真实采集检查需要图形环境。
