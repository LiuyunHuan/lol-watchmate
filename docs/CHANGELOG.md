# 更新日志

## 0.5.1 · 2026-10-24

- 死亡计数增长改为两次独立读取确认，单帧 OCR 跳值不触发；头像/击杀栏已报过的死亡与后到的计数合并。
- 对线计分板有绿色生命条时不把灰色英雄脸与误读数字当成阵亡计时；计时 OCR 加强置信度与字形检查。
- 击杀栏右侧英雄必须唯一绑定选手；不能覆盖同帧的明确存活证据。
- 同一选手五秒内最多开串一次，主进程统一限制头像、KDA、手动检测和弹幕延伸。冷却期间重复信号直接消耗，不在五秒后补播；晚到弹幕延伸丢弃。
- 继续允许回放开串，保留语音优先级、保护规则及低频云端截图。详见 [验证报告](VALIDATION-v0.5.1.md)。

## 0.5.0 · 2026-10-24

- 搜梗改为用户手动发起：选选手、重点搜索、截止日期、进度与取消。名单变化、开始观赛、换局、重启不发起搜梗。
- 百炼 Qwen 原生联网检索替代博查；搜梗限定虎扑，战术问答保留赛事和版本检索。使用真实来源元数据，不从生成文本拼出链接。
- 读取虎扑公开正文、热门回复、普通评论与引用关系；按时间筛选。每人有搜索/页数/评论数上限，公开帖子共享缓存。评分 App 入口明确标为未读取。
- 候选区保留原文、来源、评论 ID、点赞、解释、改写标记和条件；审核选入后才可自动播报。特殊条件未知时不自动使用。
- 梗库增加稳定 ID、手动增改删、启停、按对象筛选、撤销删除和去重墓碑；Markdown 导入与旧库迁移保留。
- 删除、停用或编辑旧句同步清理语音队列。保留 v0.4.2 本地死亡触发、回放容忍、语音优先级及低频截图策略。
- 搜索工具和模型 Token 分别记录；未知用量显示未知。旧博查费率不用于 Qwen。

**验证限制**：真实公开虎扑采集、模拟服务、规则测试与打包桌面流程已验证。真实 Qwen 验证因隔离进程无法解密现有凭据未执行；用户选择先完成其他验证，因此不是已经通过全部上线验收。详见 [验证报告](VALIDATION-v0.5.md)。
