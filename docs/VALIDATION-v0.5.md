# v0.5.0 验证与交付记录

2026-10-24。此次交付是可测试版本，**不代表真实 Qwen 候选质量已经验收通过**。用户已明确选择暂缓重新填写密钥，先完成其他验证。

## 已完成的变更

- 博查 UI、连通性测试和请求路径移除，搜梗/战术检索使用同一百炼密钥。搜梗默认 qwen-plus，DashScope 原生来源元数据，不采用生成文本里的链接。
- 名单更新、开始观赛、换局和重启没有自动搜梗调用。手动选择名单、重点搜索、日期范围与取消；搜索独立于观看状态，不开启采集或语音。
- 公开虎扑正文、热评、普通评论及引用关系采集；限页/限评论/限请求。候选包含原文、目标、评论 ID、链接、点赞、日期、解释、条件和改写标记；未审核不会播报。
- 稳定 ID 的梗库增删改、批量选入、启停、筛选、撤销、Markdown 导入和旧库迁移。删除/编辑旧句留下去重记录，停用和删除同步撤下待播语音。
- 特殊场景缺少证据时不自动播报；不增加现场付费分析。死亡识别算法、截图频率及语音优先级未改成昂贵视频服务。

## 评分页的支持范围

可读取的是公开**评分讨论帖及可见评论**。两个赛后帖子中发现 App 评分入口，明确输出“评分页未读取”。实际允许域名上的 HTTPS 评分入口会作一次有限访问，占页面预算；目前没有经验证的独立评分数据结构解析器，不能称为已抓取评分页热评。不会启动 App、绕过登录、猜测私有 API，也不把普通评论冒充评分热评。
