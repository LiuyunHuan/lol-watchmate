# v0.4.1：战绩识别成功但没有开串

日期：2026-10-23。用户报告本场选手的英雄、战绩、死亡变化能实时更新，但 TheShy 和 Rookie 阵亡后没有玩梗。截图同时显示应用已停止、历史阶段为回放；仅凭截图不能断言当时所有状态，所以用事件时间序列复现链路。

## 原因与修复

统计稳定器 `ScoreboardStats` 已要求两次读数确认死亡数。旧 `BroadcastDetector` 收到确认结果后，又等待两个连续携带增长证据的帧；实际本地检测约每500ms尝试、KDA约2秒读取，中间没有KDA的帧会清掉待触发状态。因此文字板左侧已更新死亡数，事件数仍可能为0。

现在仅对主进程统计稳定器确认的死亡数增长直接生成事件，不再重复等待；头像/击杀栏仍保持两帧确认。标记已经由头像/击杀栏触发、尚未反映到KDA的死亡，后到的累计数字只同步一次，不重复开串，即使中间已经复活。暂停、屏蔽、过时帧、回放、首次接入基线等守卫保留。

停止状态显示“已暂停 · 不触发”，未共享窗口时显示“等待共享窗口”，避免把历史回放标识误当成当前检测状态。没有放开回放重复播报，也没有增加云端调用频率。

- 新增4项检测器回归：已确认计数触发、未经确认单帧不能触发、头像后延迟KDA不重复且下次死亡可触发、保护/回放/过时/初始基线。
